# IPA webfonts

Doulos SIL remains the default; Andika provides a sans-serif alternative. The existing Doulos SIL webfont and OFL notice are retained.

Andika Regular 7.000 is copied unmodified from the official SIL package:
https://software.sil.org/downloads/r/andika/Andika-7.000.zip

The regular WOFF2 file and its OFL.txt are included. No other Andika styles are bundled.

ipa-font-coverage.json stores Unicode cmap ranges extracted from both font files, used by QA to verify coverage of every chart input target. Glyph silhouettes and rule cutouts are measured with the selected webfont.
