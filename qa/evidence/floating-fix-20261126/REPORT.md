## 原因と修正

### 移動中のグレーの矩形

入力パネルの移動ボタン、マップの移動ボタン、マップの閉じるボタンにはブラウザ標準のタッチ押下表示が設定されていました。Chromeで取得した修正前の -webkit-tap-highlight-color は rgba(0, 0, 0, 0.18) でした。移動する要素に対して、このネイティブ表示が矩形として残る原因になります。

入力パネルとマップ内の -webkit-tap-highlight-color を transparent にしました。両ウィンドウの枠・背景・CSSの影、各ボタンの既存デザイン、キーボード用のフォーカス枠を維持しています。

### マップが入力パネルを横切れない

chart.html の placeMap() は、マップが入力パネルに重なると、パネルの上下左右にある候補位置へ移す処理を毎回実行していました。ドラッグ中にもこの処理が働き、指定した場所から押し戻されていました。

ユーザーがドラッグまたは矢印キーでマップを配置した後は、その位置を優先します。初期配置では既存の入力パネル回避を使い、手動移動では重ね合わせを許可します。画面端とセーフエリアの制限は維持します。手動配置したマップは入力パネルの移動によって押し出されません。

入力パネルとマップを操作・フォーカスしたときは、そのウィンドウを前面にします。ヘッダーの全体図ボタンから開くときもマップを前面にします。両ウィンドウは拡大チャートより上の層に置き、前後を切り替えてもチャートの裏に隠れないようにしました。
