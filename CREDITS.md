## Unicode names

Vowel hover descriptions use the Unicode character name and U+ code point. These names are identifiers, not translated phonetic descriptions. Tooltip metadata does not change the inserted Unicode text.

## Display-only mark positioning

The display layer uses SVG glyph outlines extracted from the bundled Doulos SIL and Andika fonts, with their original OFL notices retained. `fonts/positioned-diacritics.json` is generated by `tools/generate-positioned-diacritics.py`. Position metadata belongs to the editor presentation and its Undo/Redo history; plain-text copying retains the original Unicode characters. The existing above/below ring code-point pair remains supported.
